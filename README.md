# Portfolio — Kartikey Kumar

Production-grade, highly individualistic personal portfolio built with **Vite 6, React 19, TypeScript 5.9+, Tailwind CSS v4, shadcn/ui, and Motion**.

Deployable seamlessly on **Vercel**.

---

## Architecture & Core Innovations

### 1. The Dual Spectrum (Atmosphere Engine)
Reflects Kartikey's complex persona (*chaotic, moody, sunny, cold, adaptive, dark*) through 3 dynamic atmospheric states:
- **Glacial Abyss (`abyss`)**: Cold obsidian space, ice cyan, terminal phosphor green, calculating systems programming aesthetic.
- **Solar Flare (`solar`)**: Warm amber, sunburst gold, radiant optimism, human-centered product craft.
- **Chaotic Flux (`flux`)**: Kinetic reactive purple/pink ambient particle entropy reacting to mouse gravity and scroll physics.

### 2. Hierarchical Multi-Lens Projection Engine
Non-destructive lens switcher that guarantees **every project and experience remains fully accessible**:
- **Full-Stack Engineer** (`all`, `nodejs`, `python`)
- **Backend Engineer** (`all`, `nodejs`, `python`)
- **DevOps & Cloud Platform**
- **Data Engineering & Streaming Intelligence**
- **Systems & Core Infrastructure**
- **Software Engineering (Generalist SDE-1 / Systems)**
- **Workflow & Platform Automation**
- **Distributed Systems & AI Infrastructure**
- **Omni-Mode** (Unfiltered full chronicle)

### 3. Dual Exploration Modes
- **Story Mode**: A cinematic, vertical scrollytelling journey through 5 chapters connecting real engineering milestones to their verified repositories.
- **Inspector Mode**: A high-density engineering catalog, interactive terminal emulator (`DevTerminal`), and spec modal inspector.

### 4. Single Source of Truth & Identity Resolution
- Decoupled configuration validated at boot via **Zod 4** (`src/config/schema.ts`).
- Pre-baked local git commit streams mapped across:
  - Primary GitHub: [`@zed-inn`](https://github.com/zed-inn)
  - Academic GitHub: [`@masked-redhat`](https://github.com/masked-redhat)
  - Kaggle: [`@skhull3`](https://www.kaggle.com/datasets/skhull3/indian-institutes)
